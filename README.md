# Smart Waste

เว็บต้นแบบระบบแจ้งและติดตามปัญหาขยะล้นภายในมหาวิทยาลัย (สแกน QR → ถ่ายรูป → ส่ง)

## ฟีเจอร์
- **ผู้แจ้ง:** แจ้งขยะล้น ติดตามสถานะ รายการ แผนที่ Dashboard Chatbot
- **เจ้าหน้าที่:** รับงาน เปลี่ยนสถานะ แนบรูปหลังเก็บ ดูข้อความ LINE
- **ผู้ดูแลพื้นที่:** ภาพรวมทุกโซน รับ Escalation มอบหมายงานใหม่
- กฎระบบ: ต้องแนบรูป, รวมเรื่องซ้ำของถังเดียวกันภายใน 30 นาที, เตือนนาทีที่ 20, ส่งต่อผู้ดูแลนาทีที่ 30
- ปุ่ม "เร่งเวลา +10 นาที" ใช้ทดสอบการเตือนและ Escalation

## ข้อจำกัดของต้นแบบ
- ไม่เปิดกล้อง/GPS จริง (จำลองการสแกน QR และพิกัด)
- ไม่ส่ง LINE จริง แสดงเป็นหน้าตาข้อความเท่านั้น
- ข้อมูลอยู่ในหน้าเว็บ รีเฟรชแล้วกลับเป็นข้อมูลตัวอย่าง

## รันในเครื่อง
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
